# 🌸 K-Nearest Neighbors (KNN) Classification on Iris Dataset

This project demonstrates a machine learning pipeline using the **K-Nearest Neighbors (KNN)** algorithm to classify flower species in the classic **Iris dataset**. It includes data preprocessing, model training, hyperparameter tuning (for optimal K), and various visualizations.

---

## 📌 Features

- 🔍 Loads and preprocesses the Iris dataset
- 📏 Standardizes features using `StandardScaler`
- ⚙️ Trains KNN classifier for K = 1 to 20
- 🧪 Automatically finds the best `K` based on test accuracy
- 📈 Plots Accuracy vs K
- 📊 Displays Confusion Matrix and Classification Report
- 🌐 Interactive 3D Visualization using Plotly
- 🧭 2D Decision Boundary visualized via PCA

---

## 🧠 Algorithm

- **Model:** K-Nearest Neighbors (KNN)
- **Dataset:** Iris (3 species, 4 features)
- **Metric:** Accuracy Score, Confusion Matrix
